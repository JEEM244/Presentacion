# Mi futuro profesional — Presentación personal

Página web para editar la portada y el apartado de presentación personal del Proyecto Integrador de Aprendizaje (PIA).

## Abrir la página

1. Descarga o clona este repositorio.
2. Abre `index.html` en un navegador actualizado.
3. Completa nombre, grupo, fecha y docente (si corresponde).
4. Revisa y edita el texto de presentación personal.
5. Usa **Exportar a Word** para generar `PIA_Presentacion_Personal.doc`.
6. Usa **Imprimir / PDF** para imprimir o guardar la vista previa como PDF.

No requiere instalación, servidor, frameworks ni dependencias externas.

## Estructura

- `index.html`: interfaz y vista previa.
- `css/styles.css`: estilos adaptables y estilos de impresión.
- `js/app.js`: campos editables y actualización de vista previa.
- `js/export-word.js`: generación del archivo compatible con Microsoft Word.

## Nota sobre el contenido

La página prepara la portada, la presentación personal y un índice orientativo del PIA. Los apartados de pruebas vocacionales, autoanálisis, investigación, entrevista, línea del tiempo, conclusión y bibliografía aparecen como pendientes porque deben completarse con resultados y fuentes reales. El borrador de presentación debe revisarse y personalizarse antes de entregar.
